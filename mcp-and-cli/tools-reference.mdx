Falconer MCP exposes tools your AI client can use to find, read, create, update, organize, and manage Falconer documents.

![Claude.ai connector settings showing Falconer MCP tool permissions](/images/falconer-mcp-tool-permissions.png)

## Use Falconer knowledge and connected tools

`ask_falcon` answers questions from your workspace with citations. For an action or a structured result, your AI client can call a named MCP tool directly. In addition to the document tools below, the hosted server exposes tools for searching connected knowledge, code, pull requests, issues, people, meetings, and the user’s connected services. Available tools depend on your permissions, connections, and organization settings.

| Need | Direct tools to look for |
| --- | --- |
| Find connected knowledge | `document_search`, `meeting_notes_search`, `source_tree`, `people_search` |
| Explore engineering work | `code_search`, `code_tree`, `read_file`, `git_raw`, `github_pull_request_search`, `linear_issue_search` |
| Work with connected accounts | `list_integrations`, `gmail_search`, `calendar_list_events`, `calendar_find_free_time` |
| Take an action | `linear_create_issue`, `calendar_create_event`, `gmail_create_draft`, or the document tools below |
| A tool is available only when the corresponding source, account, and permission are available to you. A Gmail draft is saved for your review and is not sent. Calendar changes can invite or notify attendees, so inspect the target account and event before calling them. Not every web-chat capability runs in an MCP client: browsing a page, running a coding environment, generating media, and work that depends on a live Falconer conversation stay in the web app. |  |

For example, ask your client to find a relevant document, read it, then use a targeted edit tool to update one section. For calendar changes or external actions, review the exact target and result in your client. `ask_falcon` remains a question-answering tool; it does not perform document edits on your behalf.

## Organization discovery

| Tool | What it does |
| --- | --- |
| `list_organizations` | Lists Falconer organizations available to the MCP connection. |

If only one organization is available, your client can usually omit `organizationId`. If multiple organizations are available, pass the selected `organizationId` on future Falconer tool calls.

## Find and read documents

| Tool | What it does |
| --- | --- |
| `search` | Searches Falconer documents by keyword query, semantic query, or both. |
| `read` | Reads a Falconer document by document ID, title, or Falconer URL. |

Use `search` when you do not know the exact document. Use `read` before editing so the agent can copy exact Markdown text from the current document.

## Create and update documents

| Tool | What it does |
| --- | --- |
| `create` | Creates a Falconer document from Markdown. |
| `replace_document_content` | Replaces exact Markdown text in a document. |
| `insert_document_content` | Inserts Markdown before or after exact anchor text, or at the start or end of a document. |
| `delete_document_content` | Deletes exact Markdown text from a document. |
| `edit` | Legacy exact replacement tool. Prefer the targeted content tools above. |
| `overwrite` | Replaces the full Markdown body of a document. |
| `delete` | Archives a Falconer document by ID. |

Prefer `replace_document_content`, `insert_document_content`, and `delete_document_content` for targeted updates. Use `overwrite` only when the whole document needs to be rewritten.

## Comments

| Tool | What it does |
| --- | --- |
| `list_document_comments` | Lists comment threads on a Falconer document. |
| `reply_to_comment` | Replies to an existing document comment. |
| `edit_comment` | Edits one of your existing comments. |
| `delete_comment` | Deletes one of your existing comments. |
| `resolve_comment` | Resolves a document comment thread. |
| `unresolve_comment` | Reopens a resolved document comment thread. |

## Navigation and folders

| Tool | What it does |
| --- | --- |
| `list_nav_children` | Lists visible child folders and documents for a navigation location. |
| `get_nav_tree` | Gets a visible Falconer navigation tree. |
| `get_folder` | Gets folder metadata and visible one-level children. |
| `create_folder` | Creates a Falconer folder. |
| `update_folder` | Updates a folder title or description. |
| `reorder_folder_children` | Sets the full direct-child order for a folder. |
| `reorder_nav_children` | Sets the full direct-child order for a folder or document nav item. |
| `move_nav_item` | Moves a folder or document navigation item. |
| `move_document` | Moves a document navigation placement by document ID. |
| `publish_document` | Publishes a private document into company navigation. |
| `delete_folder` | Archives a folder and its documents. |

Inspect navigation placement before moving documents or folders. If a document move or publish reports ambiguous placement, retry with the returned `sourceNavItemId`.

## Public docs sites

Tools for managing a space's [docs site](/public-docs/overview). Publishing, settings, passwords, and custom domains need an organization owner.

| Need | Tools |
| --- | --- |
| Sites and builds | `list_docs_sites`, `get_docs_site`, `create_docs_site`, `set_docs_subdomain`, `trigger_docs_build`, `list_docs_builds`, `get_docs_build`, `publish_docs_build`, `unpublish_docs_site`, `cancel_docs_build`, `delete_docs_build`, `retry_docs_build_index`, `request_docs_preview`, `get_docs_preview`, `get_docs_broken_links` |
| Settings and access | `get_docs_site_config`, `update_docs_site_config`, `get_docs_redirects`, `set_docs_redirects`, `set_docs_site_password`, `clear_docs_site_password`, `sign_out_docs_site_visitors` |
| Custom domain | `get_docs_custom_domain`, `set_docs_custom_domain`, `check_docs_custom_domain`, `activate_docs_custom_domain`, `disable_docs_custom_domain`, `remove_docs_custom_domain` |
| Site navigation | `get_docs_view`, `create_docs_view_page`, `create_docs_view_folder`, `update_docs_view_item`, `move_docs_view_items`, `reorder_docs_view_children`, `remove_docs_view_item` |
| Files behind the site | `list_file_view_files`, `read_file_view_file`, `write_file_view_file`, `create_file_view_page`, `create_file_view_directory`, `move_file_view_file`, `delete_file_view_file`, `publish_file_view_page`, `upload_file_view_file`, `get_file_view_download_url` |

`publish_docs_build` also rolls back when you pass an older build. `set_docs_redirects` replaces the whole list, so pass the list you read as `base` to merge your edits.

## Permissions and media

| Tool | What it does |
| --- | --- |
| `update_document_permissions` | Updates document ACL mode, organization-wide access, public access, user access, or group access. Direct permission changes on inherited documents switch them to explicit mode automatically. |
| `upload_media` | Uploads supported images, videos, audio, or file attachments and returns a snippet you can insert into a document. |

## Permissions

The MCP connection uses the permissions of the authenticated Falconer user or organization bot. Your client can only access documents, folders, comments, and permissions that identity can access in Falconer.
