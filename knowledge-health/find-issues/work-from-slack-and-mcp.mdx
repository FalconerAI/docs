Ask about findings in Slack, or read and update them from an MCP client.

## From Slack

With Slack connected, mention Falcon in a channel or direct message:

```
@Falcon what did the last Knowledge Health audit find?
```

Falcon searches the same findings shown on the Knowledge Health page and replies with their titles, categories, and severities. To connect Slack, see [Slack](/integrations/slack).

## From an MCP client

Connect the Falconer MCP server to Claude Code, Cursor, or Codex. Four tools work with findings:

| Tool | What it does |
| --- | --- |
| `knowledge_health_get_summary` | Shows the Knowledge Health score, open finding counts, the last and next run, and the top open findings. |
| `knowledge_health_list_findings` | Lists open findings for one category. |
| `knowledge_health_get_finding` | Shows the full details of one finding. |
| `knowledge_health_update_finding` | Updates a finding's status or owner. |

See the [MCP quickstart](/mcp-and-cli/quickstart) and the [MCP tools reference](/mcp-and-cli/tools-reference).
