What a docs site costs, which add-ons are billed in credits, and every limit in one place.

## What's included

Public docs are enabled per organization; contact Falconer if you don't see the option.
Once they're on, building, publishing, hosting on `your-subdomain.falconer.site`, site search, Ask the docs, and password protection are part of the feature.
The two features below are billed separately, as add-ons.

## Add-ons

Two features are paid add-ons, billed per site in [credits](/plans-and-pricing/how-credits-work).

| Add-on | Credits | What it does |
| --- | --- | --- |
| [Custom domain](/public-docs/custom-domain) | 15,000 per month | Serve the site on `docs.example.com` or `example.com/docs` |
| [White-label branding](/public-docs/customize-your-site#white-label-branding) | 10,000 per month | Remove the Falconer mark from the site |

- The charge starts when the add-on is enabled and renews monthly while it stays on.
- Turning an add-on off stops the next renewal; the current period isn't refunded.
- Only an organization owner who can manage billing can turn an add-on on or off.

## Limits

### Content

| Limit | Value |
| --- | --- |
| Image in a page | 100 MB |
| Logo or favicon | 5 MB |
| Any uploaded file | 100 MB |
| Text or code file edited in Falconer | 5 MB |
| OpenAPI document | 10 MB |
| Page path | 512 characters |

### Site settings

| Limit | Value |
| --- | --- |
| Site name | 200 characters |
| Search description | 500 characters |
| Navbar links | 10, with labels up to 40 characters |
| Footer | 6 columns of 10 links each |
| Social links | 20 |
| SEO meta tags | 30 |
| Analytics providers | 10, each snippet up to 10,000 characters |
| Custom domain path | 120 characters |

### Publishing

| Limit | Value |
| --- | --- |
| Redirects | 1,000 per site after wildcards are expanded |
| Builds kept | The five most recent, plus the live one |
| Preview builds kept | Five per person per site |
| Concurrent builds | One per site; a second request joins the queue |

### Access

| Limit | Value |
| --- | --- |
| Site password | 12 to 72 characters |
| Visitor session on a password-protected site | 7 days |

### Ask the docs

The assistant has daily fair-use limits so one site can't consume the organization's capacity.

| Limit | Per day |
| --- | --- |
| One visitor on one site | 50 questions |
| One network address on one site | 200 questions |
| Whole organization, across its sites | 500 questions |

A visitor over a limit can't ask more questions until it resets.
Site search isn't limited.
