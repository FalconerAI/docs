Connect the tools your team already uses so Falconer can search, write, and keep documentation up to date across your stack.

Each integration takes a few clicks to set up. For the general connection flow, prerequisites, and what each button means, see [Connect sources](/set-up/connect-sources).

## Available integrations

| Integration | What it brings to Falconer |
| --- | --- |
| [Slack](/integrations/slack) | Ask questions and manage docs directly from Slack. |
| [GitHub](/integrations/github) | Connect repositories to ask about your codebase. |
| [Linear](/integrations/linear) | Sync issues and projects for context-aware answers. |
| [Notion](/integrations/notion) | Import pages and databases from your workspace. |
| [Confluence](/integrations/confluence) | Sync documentation from your Confluence spaces. |
| [Google Drive](/integrations/google-drive) | Connect your personal Google Drive files. |
| [Google Workspace](/integrations/google-workspace) | Sync documents across your Google Workspace. |
| [Gmail](/integrations/gmail) | Import emails and threads from Gmail. |
| [Zendesk](/integrations/zendesk) | Import help center and support articles. |
| [Granola](/integrations/granola) | Sync meeting notes and transcripts. |
| [Bitbucket](/integrations/bitbucket) | Connect Bitbucket repositories to ask about your codebase. |
| [Slab](/integrations/slab) | Sync posts from your Slab knowledge base. |
| [Jira](/integrations/jira) | Sync issues, projects, releases, boards, and sprints. |
| [Asana](/integrations/asana) | Sync projects and tasks for context-aware answers. |

See which integrations are available for your plan on the [pricing page](https://falconer.com/pricing).
