A new engineer reads the architecture doc in their first week and trusts it. A week later they learn half of it is out of date, and by then it has already shaped their decisions. Agents make the same mistake faster, because they never stop to ask in standup.

Falconer is built to stop that drift. It reads your code, tickets, wikis and threads, finds where they disagree, and keeps docs current as the product changes.

<Card icon="plug" href="/set-up/connect-sources" cta="Connect sources">
  ## Connect sources

  **Start with the tools you already use.**

  Connect GitHub for code and pull requests, Linear for issues, Slack for conversations, and Notion, Google Docs or Confluence for existing docs. Falconer indexes synced sources continuously and reads live sources on demand, so nothing has to be migrated first.
</Card>

<Card icon="scan" href="/get-started/how-falconer-works/" cta="How Falconer works">
  ## Falconer scans

  **Three ways to read, one answer.**

  Semantic search finds content by meaning, full-text search finds exact names and error strings, and a knowledge graph maps how docs, code, people and systems relate. Together they let Falcon answer a question like *"Who owns the payment service?"* by reasoning across sources instead of matching one page.
</Card>

<Card icon="heart-rate-monitor" href="/update/find-and-fix-outdated-docs/" cta="Find outdated docs">
  ## Health issues

  **A last-updated date cannot tell you a doc is wrong.**

  Knowledge Health reads the content itself and scores your docs from 0 to 100 on coherence, coverage, freshness and density. It catches docs that contradict each other, topics never written down, docs that fell behind the code, and duplicates. Each problem becomes a finding you can fix, hand to Falcon or dismiss.
</Card>

<Card icon="refresh" href="/update/auto-update-docs/" cta="Set up auto-update">
  ## Auto-update

  **Merge the code, and the docs catch up.**

  Every merged pull request starts a run: Falcon finds the affected docs, drafts edits, and notifies each owner in Slack. Full self-driving mode applies changes right away, and review mode waits for approval. Auto-update works on org-wide and public docs, not private ones.
</Card>

<Card icon="pencil" href="/write/write-a-doc/" cta="Write a doc">
  ## Falconer writes docs

  **From a prompt to a cited first draft.**

  Ask Falcon in chat, with `/` in the editor, or with `@Falcon` in Slack for a runbook, onboarding guide, API reference or changelog. Every claim cites your code, tasks or docs, so you can check the source before you trust it.
</Card>

<Card icon="world" href="/use-cases/manage-permissions/share-a-doc/" cta="Share a doc">
  ## Publish docs

  **Customers read what actually changed.**

  Publish docs straight from the same knowledge base your team works in, with no separate site to keep in sync. When an update is accepted, the published page reflects it too, so readers always see the current version.
</Card>

<Card icon="infinity" href="/get-started/how-falconer-works/" cta="See the full loop">
  ## The self-updating loop

  **Docs that keep up on their own.**

  Code changes, Falcon drafts the fix, and the owner accepts it in one click. Knowledge Health catches whatever slips through, so your team, customers and agents can trust the docs without anyone remembering to update them.
</Card>

(() => {
  const init = () => {
    const cards = [...document.querySelectorAll('.sl-markdown-content .docsite-card')];
    if (!cards.length || document.querySelector('.fx-track')) return;
    const track = document.createElement('div');
    track.className = 'fx-track';
    const spine = document.createElement('div');
    spine.className = 'fx-spine';
    spine.setAttribute('aria-hidden', 'true');
    cards[0].before(track);
    track.append(spine, ...cards);
    const reduce = matchMedia('(prefers-reduced-motion: reduce)').matches;
    const fine = matchMedia('(hover: hover) and (pointer: fine) and (min-width: 50em)').matches;
    cards.forEach((c, i) => {
      c.style.setProperty('--fx-delay', `${(i % 3) * 0.04}s`);
      c.querySelectorAll('[data-card-icon] path').forEach(p => p.setAttribute('pathLength', '1'));
      const inf = c.querySelector('[data-card-icon="infinity"] path');
      if (inf) { const comet = inf.cloneNode(); comet.classList.add('fx-comet'); inf.after(comet); }
      c.insertAdjacentHTML('afterbegin', '<span class="fx-glow" aria-hidden="true"></span><span class="fx-dot" aria-hidden="true"></span>');
    });
    if (reduce || !('IntersectionObserver' in window)) {
      cards.forEach(c => c.classList.add('is-in', 'icon-in'));
    } else {
      const io = new IntersectionObserver(entries => {
        entries.forEach(e => { if (e.isIntersecting) { e.target.classList.add('is-in'); io.unobserve(e.target); } });
      }, { threshold: 0.18, rootMargin: '0px 0px -8% 0px' });
      cards.forEach(c => io.observe(c));
      const iconIo = new IntersectionObserver(entries => {
        entries.forEach(e => { if (e.isIntersecting) { e.target.closest('.docsite-card').classList.add('icon-in'); iconIo.unobserve(e.target); } });
      }, { rootMargin: '0px 0px -35% 0px' });
      cards.forEach(c => { const icon = c.querySelector('[data-card-icon]'); if (icon) iconIo.observe(icon); });
    }
    let ticking = false;
    const update = () => {
      const r = track.getBoundingClientRect();
      const p = Math.min(1, Math.max(0, (innerHeight * 0.6 - r.top) / r.height));
      track.style.setProperty('--fx-progress', p.toFixed(3));
      ticking = false;
    };
    addEventListener('scroll', () => { if (!ticking) { ticking = true; requestAnimationFrame(update); } }, { passive: true });
    update();
    if (!fine || reduce) return;
    cards.forEach(card => {
      card.addEventListener('pointermove', e => {
        const r = card.getBoundingClientRect();
        const x = (e.clientX - r.left) / r.width, y = (e.clientY - r.top) / r.height;
        card.classList.add('is-tilting');
        card.style.setProperty('--mx', `${x * 100}%`);
        card.style.setProperty('--my', `${y * 100}%`);
        card.style.setProperty('--ry', `${(x - 0.5) * 6}deg`);
        card.style.setProperty('--rx', `${(0.5 - y) * 6}deg`);
      });
      card.addEventListener('pointerleave', () => {
        card.classList.remove('is-tilting');
        card.style.setProperty('--rx', '0deg');
        card.style.setProperty('--ry', '0deg');
      });
    });
  };
  document.readyState === 'loading' ? document.addEventListener('DOMContentLoaded', init) : init();
})();
